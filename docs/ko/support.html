문의하기

문제나 제안이 있으시면 App Store 개발자 페이지의 연락처를 통해 문의해 주세요.

자주 묻는 질문

구매한 PRO를 다른 기기에서 쓰려면 어떻게 하나요?
같은 Apple ID로 로그인한 뒤 구독 화면의 "구매 복원하기"를 눌러 주세요.
구독은 어떻게 취소하나요?
iOS 설정 → Apple ID → 구독에서 언제든지 관리하고 취소할 수 있습니다. 현재 기간 종료 24시간 전까지 취소하지 않으면 자동으로 갱신됩니다.
기기 간 데이터가 동기화되지 않아요.
모든 기기에서 같은 Apple ID로 iCloud에 로그인되어 있고, iOS 설정에서 이 앱의 iCloud 사용이 켜져 있는지 확인해 주세요. 네트워크 연결도 필요합니다.
저장된 데이터를 모두 지우고 싶어요.
앱 설정에서 "모든 데이터 초기화"를 누르면 체크리스트, 회고 기록, 북마크가 모두 삭제됩니다. 이 작업은 되돌릴 수 없습니다.
어떤 기기에서 쓸 수 있나요?
iPhone, iPad, Mac에서 사용할 수 있습니다.
