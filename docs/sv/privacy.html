Integritetspolicy

Senast uppdaterad: februari 2026

Appen 100 Misstag (nedan "appen") värnar om din integritet. Den här policyn beskriver vilken information appen samlar in och hur den används.

Information vi samlar in

Appen lagrar följande data lokalt på din enhet:

  • Status för checklistan (vilka misstag du har bockat av)
  • Innehållet i din reflektionsdagbok (svar som du själv har skrivit)
  • Din lista med bokmärken
  • Status för din appprenumeration

Dessa data kan synkas via iCloud (CloudKit) kopplat till ditt Apple-ID mellan enheter som är inloggade med samma Apple-ID.

Information vi inte samlar in

  • Personuppgifter som namn, e-postadress och telefonnummer
  • Platsinformation
  • Åtkomst till kontakter, kamera, mikrofon och andra enhetsfunktioner
  • Användningsanalys eller annonsspårning

Delning med tredje part

Appen säljer eller delar inga insamlade data med tredje part.

iCloud-synkning

Om du använder iCloud-synkning överförs och lagras data via Apples CloudKit-infrastruktur. Apples integritetspolicy gäller för hanteringen av dessa data. Apples integritetspolicy: apple.com/legal/privacy

Köp i appen

Prenumerationer och köp i appen hanteras via Apple App Store. Betalningsinformationen hanteras av Apple och är inte tillgänglig för apputvecklaren.

Radera data

Du kan radera alla data som är lagrade i appen via Inställningar i appen → "Återställ all data". Om du vill radera data som har synkats till iCloud kan du göra det i iOS Inställningar → Apple-ID → iCloud → Hantera lagring.

Barns integritet

Appen samlar inte avsiktligt in personuppgifter från barn under 14 år.

Ändringar i policyn

Om integritetspolicyn ändras uppdateras den här sidan. Viktiga ändringar meddelas via en appuppdatering.

Kontakt

Om du har frågor om integritet kan du kontakta oss via kontaktuppgifterna på utvecklarsidan i App Store.
