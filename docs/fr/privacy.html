Politique de confidentialité

Dernière mise à jour : février 2026

L'app 100 Erreurs Dev (ci-après « l'app ») accorde une grande importance à vos données personnelles. La présente politique décrit les informations que l'app collecte et la façon dont elles sont utilisées.

Informations collectées

L'app enregistre localement sur votre appareil les données suivantes :

  • Votre avancement dans la checklist (les erreurs que vous avez cochées)
  • Le contenu de votre journal de rétro (les réponses que vous avez rédigées)
  • Votre liste de favoris
  • L'état de votre abonnement à l'app

Ces données peuvent être synchronisées via iCloud (CloudKit), lié à votre identifiant Apple, entre les appareils connectés avec le même identifiant Apple.

Informations non collectées

  • Informations d'identification personnelle comme le nom, l'adresse e-mail ou le numéro de téléphone
  • Données de localisation
  • Autorisations d'accès à l'appareil, comme les contacts, l'appareil photo ou le micro
  • Données d'analyse d'usage ou suivi publicitaire

Partage avec des tiers

L'app ne vend ni ne partage aucune des données collectées avec des tiers.

Synchronisation iCloud

Si vous utilisez la synchronisation iCloud, vos données sont transmises et stockées via l'infrastructure CloudKit d'Apple. La politique de confidentialité d'Apple s'applique au traitement de ces données. Politique de confidentialité d'Apple : apple.com/legal/privacy

Achats intégrés

Les abonnements et les achats intégrés sont traités via l'App Store d'Apple. Les informations de paiement sont gérées par Apple, et le développeur de l'app n'y a pas accès.

Suppression des données

Vous pouvez supprimer toutes les données enregistrées dans l'app via Réglages de l'app → « Réinitialiser toutes les données ». Pour supprimer les données synchronisées dans iCloud, allez dans Réglages iOS → identifiant Apple → iCloud → Gérer le stockage, puis supprimez-les.

Données personnelles des enfants

L'app ne collecte pas sciemment de données personnelles auprès d'enfants de moins de 14 ans.

Modifications de la politique

Si la politique de confidentialité change, cette page sera mise à jour. Les modifications importantes seront signalées par une mise à jour de l'app.

Contact

Pour toute question relative à vos données personnelles, contactez-nous via les coordonnées indiquées sur la page développeur de l'App Store.
